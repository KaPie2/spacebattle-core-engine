# План разработки

Цель: Разработка фундамента игрового движка, включающего IoC-контейнер, механизм автогенерации адаптеров и многопоточное серверное ядро.

## План работ

### Блок 1: Инфраструктура и IoC
- Базовый IoC-контейнер и `Root Scope`.
- Иерархия `Scopes` с использованием `ThreadLocal`.
- Обобщенная стратегия сборки `MacroCommand`.
- Двухуровневый маршрутизатор исключений (Exception Handler).

### Блок 2: Кодогенерация и Потоки
- [x] Чтение метаданных интерфейсов через Reflection (`IMovingObject`).
- [x] Шаблонизатор адаптеров и фабрик `IAdapterFactory<T>` с вызовами `IoC.Resolve`.
- [x] In-Memory компиляция сгенерированного кода через Roslyn (`CSharpCompilation`).
- [x] Декларативная настройка стратегий вычислений через атрибут `[Adapter]`.
- [x] Автоматическое внедрение зависимостей команд (`RegisterAutoInjectCommand`).
- [x] Базовый цикл `GameThread` (Event Loop / Actor Pattern) с неблокирующей очередью `BlockingCollection<ICommand>`.
- [x] Нагрузочное и стресс-тестирование очередей `GameThread` (Multiple Producers).
- [x] Валидация отсутствия взаимных блокировок (Deadlocks) при смене стратегий на лету.
- [x] Сквозной интеграционный тест связки адаптеров, IoC и потока (End-to-End).

### Блок 3: Игровая логика и Тестирование
- Интерфейсы доменной области (`IMovingObject`, `IFuelable`).
- Системные команды: `SoftStopCommand`, `HardStopCommand`.
- Журнал транзакций (Commit / Rollback) для макрокоманд.
- CI/CD интеграция и модульные тесты (>90% покрытия).
